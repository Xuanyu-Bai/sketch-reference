## 1. 背景与目标

### 1.1 行业背景
- 美术艺考（高考/校考/考研）中，**素描（头像/半身像/石膏/静物）** 训练高度依赖长期、反复临摹。
- 传统痛点：
  - **参考资料受限**：画册是 2D 的，学生只能"脑补" 3D 结构；
  - **光源不可控**：画册的光是固定的，无法模拟不同打光（顶光、伦勃朗光、侧光）；
  - **观察视角单一**：真人在模特棚里写生 3-6 小时才有一次机会；
  - **反馈缺失**：画完之后无人对照参考，只能靠记忆。

### 1.2 产品机会
把"3D 头部/半身像/石膏/静物模型 + 可控光源 + 写生视角微动"做到手机/平板/电脑上 24h 可用，让艺考生在家里、在通勤路上都能"对着模特练习"。

### 1.3 产品目标（产品层北极星指标）
- **核心**：让一个艺考生每周有效临摹时长从 **5h → 15h**。
- **次要**：单次练习完成率 ≥ 70%（30 分钟练习里至少画 20 分钟）。

## 2. 目标用户与画像

| 画像 | 占比（预估）| 关键诉求 | 设备 |
|---|---|---|---|
| **A. 高中艺考生**（高一~高三，集训期） | 60% | 大量重复训练、临摹高分卷、看自己画和参考的差距 | 手机/平板为主 |
| **B. 复读生/校考冲刺** | 20% | 高难度题目（石膏像、复杂光源、动态姿势）、时间压力训练 | 平板/电脑 |
| **C. 兴趣成人/转行者** | 15% | 慢节奏、想了解结构、看示范过程 | 任意 |
| **D. 艺考教师** | 5% | 布置作业、看学生提交、批注 | 电脑/平板 |

> 优先级排序：**A > B > D > C**。MVP 必须先打透 A。

## 3. 核心场景（用户故事）

### 场景 1：日常头像临摹（A 类）
> 作为集训生，我每天晚上回家想练 1 小时素描头像。
> 我打开 App，选"男中年 3/4 侧光"这个预设，模型自动转到对应角度，光源就位。
> 我在画板上画，画的过程中可以随时隐藏参考、对比、回到原角度。

### 场景 2：考试模拟（B 类）
> 距离校考还有 30 天，我想练"3 小时速写"。
> 我点"考试模式"，选一张图（动态人物速写），App 计时 3 小时，3 小时到自动归档。

### 场景 3：错题复盘（A 类）
> 我上周画的一张老人头像，比例不对。
> 我在 App 里打开历史记录，看到自己画的和参考图同框对比，老师（家长）能直接在图上画批注红圈。

### 场景 4：教师布置作业（D 类）
> 老师建一个班级，发一张"女青年正面顶光"，要求 2 小时内提交。
> 学生完成后，老师在 Web 后台看到全部提交，逐一点评。

## 4. 功能需求（按优先级）

### 4.1 MVP（v1.0，第一版，~8 周）— 解决"有东西练"
> 必须：✅  重要：🟡  暂不做：❌

| 模块 | 功能 | 优先级 | 备注 |
|---|---|---|---|
| **3D 模型库** | 内置 ≥ 30 个高质量头部/半身像/石膏 GLB | ✅ | 当前 `model.glb` + `nv.glb` 是占位；`scripts/meshify.py` 是生产工具 |
| | 模型按"性别/年龄/角度"标签分类 | ✅ | |
| | 用户导入自有 GLB | 🟡 | 当前 `index.html` 已支持"加载其他 GLB" |
| **视角控制** | 鼠标/手指驱动相机微动（模拟头部摆动） | ✅ | **当前原型已实现** |
| | 6 个预设视角 + 快捷键 | ✅ | 当前已实现 |
| | "框选整个模型"自适应距离 | ✅ | 当前已实现 |
| **光源控制** | 主光方向（水平角+仰角）、强度、环境光 | ✅ | 当前已实现 |
| | 至少 4 套经典布光预设（平光、侧光、顶光、伦勃朗） | 🟡 | |
| **画板** | 半透明画板叠在 3D 视图上，可用触控笔/手指绘画 | ✅ | **关键技术难点，待验证** |
| | 图层（线稿层、明暗层），可独立显隐 | 🟡 | |
| | 撤销/重做 | 🟡 | |
| **参考对比** | 弹出原图（natural.png），半透明叠加 | ✅ | 当前已实现"原图对比" |
| | 自己的画 vs 参考 同框对比 | ✅ | MVP 必备 |
| **基础设置** | 背景色切换、线框模式、水平镜像 | 🟡 | 当前已实现 |

### 4.2 v1.1（~4 周后）— 解决"练得有效"
- 🟡 **计时器 + 番茄钟**（3h 考试模拟）
- 🟡 **历史记录**：每次练习自动存画作 + 时间戳 + 模型参数
- 🟡 **批注图层**：老师/家长在画上画红圈
- 🟡 **导出**：PNG / PDF
- 🟡 **进度看板**：本周练了多少小时、覆盖了哪些模型

### 4.3 v2.0（~3 个月后）— 解决"系统化学习"
- 🟡 **课程体系**：石膏 → 头像 → 半身像 → 速写 关卡
- 🟡 **评分辅助**：上传作品 → AI 给"比例/明暗/结构"三维评分（需要外部 API）
- 🟡 **班级/教师后台**（Web）
- 🟡 **社区**：高分作品广场
- ❌ AR 写生（用手机绕一个真实物体生成 3D 参考）

## 5. 非功能性需求

| 类别 | 要求 |
|---|---|
| **平台** | iPad / Android 平板（优先） / Windows / macOS / Web 浏览器 |
| **性能** | 中端平板（iPad Air / 小米平板 5）跑 10 万面 GLB ≥ 30 FPS |
| **离线** | 核心 3D 查看 + 画板必须 100% 离线可用；评分等 AI 功能允许在线 |
| **隐私** | 学生作品默认仅本人可见；上传云端前需明确同意 |
| **付费** | 基础模型库免费；精品模型包 / AI 评分订阅 |
| **本地化** | 中文优先（艺考市场基本只在大陆） |
| **可访问性** | 快捷键、字号可调、色弱友好（明暗对比不依赖纯色） |

## 6. 关键假设 & 待验证

| 假设 | 验证方式 | 状态 |
|---|---|---|
| GLB 在中端平板能流畅渲染 10 万面模型 | `index.html` 在 iPad Safari 跑测 | ❓ 未测 |

| AI 评分 API（GPT-4V / Qwen-VL）对素描够用 | 拿 50 张作品跑评测 | ❓ 未做 |

## 7. 风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| 头部 GLB 模型版权 | 高 | 只用 Meshy.ai 自生成 + 开源模型；订阅商用库 |
| 平板触控画板延迟 | 中 | 用 OffscreenCanvas + Worker；放弃复杂滤镜 |
| 美术生学习曲线长 | 中 | v1.0 隐藏所有高级功能，先做"一键开练" |
| AI 评分效果差 | 中 | v1.0 不上评分；v2.0 才做 |
| 苹果 App Store 审核（云端模型分发） | 低 | 走 PWA + Safari Web App 先发，审核压力小 |

---

## 8. 范围之外（明确不做）

- ❌ 全 3D 雕刻（Blender 类）功能
- ❌ 真人参考照片社区（避免法律/隐私问题）
- ❌ 视频课程录制/剪辑
- ❌ 素描以外的科目（速写 / 色彩 / 设计 暂不在本 App 范围）
