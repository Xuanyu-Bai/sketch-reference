## 1. 设计风格基线

参考：`boot-v2.png/bi8Au.png`（深色玻璃感 + macOS 视觉）

**3 个关键词**：
1. **暗色画室感**——深紫黑 (#1a1a1a) 主背景，让 3D 模型是唯一视觉焦点
2. **玻璃质感**——半透明 backdrop-filter blur(8px) 让面板"浮"在画面上
3. **留白 + 香槟金点缀**——关键元素（焦点、按钮选中态）用 #c89d5e 香槟金

## 2. 设计 Token

### 2.1 颜色

#### 暗色主题（默认 / 唯一主题）

```css
--bg-base:        #1a1a1a;   /* 顶栏、侧栏背景 */
--bg-canvas:      #f5f3ee;   /* 3D 画布背景（米白，更像纸） */
--bg-elevated:    #2a2a2a;   /* 卡片、按钮 */
--bg-hover:       #3a3a3a;   /* hover 态 */
--border:         #3a3a3a;   /* 默认边框 */
--border-strong:  #5a5a5a;   /* hover 边框 */
--text-primary:   #e8e5dc;   /* 主文字 */
--text-secondary: #8a8a8a;   /* 次要文字 */
--text-muted:     #5a5a5a;   /* 弱化文字 */
--accent:         #c89d5e;   /* 香槟金，强调色 */
--accent-hover:   #d4ad75;
--accent-text:    #1a1a1a;   /* 强调色上的文字 */
--error:          #d4604f;
--success:        #6ab04c;
```

## 5. 关键交互细节

### 5.1 工具栏折叠动画

- 时长 250ms，`--ease-out`
- 折叠：工具栏宽度 320px → 0，画布宽度扩展
- 折叠按钮从 `⇥` → `⇤`
- **关键**：折叠过程中渲染不停顿，画板坐标自动适配

### 5.2 视角切换动画

- 时长 400ms，`ease-out cubic`
- 切换过程中禁用滑块和鼠标视角输入
- 切换结束有 50ms 缓冲再恢复输入

### 5.3 模型加载动画

- 加载中：3D 视图中心显示进度环（accent 色）
- 进度环下方："加载中... 45%"
- 完成后进度环消失，模型淡入（200ms opacity 0→1）

### 5.4 画板切换动画

- 工具栏自动滚动到"画板"区
- "画笔"按钮高亮 accent 色
- 工具栏外圈出现 2px accent 边框（呼吸效果 1 次）

### 5.5 Toast 提示

- 位置：底部居中，距底 24px
- 样式：玻璃面板 + icon
- 时长：错误 4s，成功 2s
- 动画：上滑 + 淡入（200ms），自动淡出

## 6. 无障碍

- 全部按钮可键盘 Tab 聚焦
- 焦点环：2px solid var(--accent)，offset 2px
- 快捷键提示在按钮 title 属性
- 滑块可用 ← → 调节
- 颜色对比度：accent on bg-base = 7.2:1（AAA）
