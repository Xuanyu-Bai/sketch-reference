## 1. 产品一句话

让美术艺考生**在平板上对一个会动会变光的 3D 模特写生**，并能直接在画面上画。

## 2. 业务背景

- 中国艺考市场规模 ~150 万考生/年；
- 集训期每天 8-12 小时训练；
- 写生环节最稀缺的是"模特"（真人模特 200-500 元/小时，画室成本高）；
- 现有 App 痛点：参考图都是 2D 静态画册，无法训练"空间感"和"光感"。

## 3. 商业模式

| 模式 | 说明 |
|---|---|
| 免费层 | 5 个基础模型 + 全部画板功能 |
| 订阅 | ¥18/月 或 ¥168/年：解锁 30 个模型 + AI 评分（v2.0）+ 班级功能 |
| 单买 | ¥30~80/包：精品模型包（如"石膏像 10 件套"） |

v1.0 上线时**只跑免费层 + 订阅**，单买模型包推迟到 v1.1。

## 5. 功能详述（PRD 主体）

### 5.1 F-001 · 模型库

#### 5.1.1 信息架构

```
模型库
├── 男
│   ├── 青年
│   │   ├── 正面
│   │   ├── 3-4 侧 ← 默认
│   │   ├── 全侧
│   │   └── 背面
│   ├── 中年
│   │   └── ...
│   └── 老年
│       └── ...
├── 女
│   ├── 青年
│   ├── 中年
│   └── 老年
└── 石膏（v1.1）
    └── ...
```

#### 5.1.2 模型卡片字段

| 字段 | 类型 | 说明 |
|---|---|---|
| 缩略图 | image | 200×200 PNG |
| 名称 | string | "男中年 3-4 侧" |
| 性别 | enum | 男/女 |
| 年龄 | enum | 青年/中年/老年 |
| 默认视角 | object | {az, el, dist} |
| 默认光源 | object | {az, el, intensity} |
| 文件大小 | number | MB |
| 三角面数 | number | — |
| 已下载 | bool | 是否在 IndexedDB |

#### 5.1.3 交互

- 点击模型卡片 → 切换模型 + 自动 fit-to-view
- 长按模型卡片 → 弹出"删除缓存" / "查看详情"
- 右上角搜索框 → 按名称模糊匹配

#### 5.1.4 边界情况

| 情况 | 处理 |
|---|---|
| 模型 GLB 加载失败 | 弹 toast"加载失败，请重试"，不切换 |
| IndexedDB 已满 | 提示"存储空间不足，请清理缓存" |
| 网络断开 + 模型未缓存 | 灰显该卡片，按钮禁用 |

### 5.2 F-002 · 视角控制（鼠标 + 触控笔 + 触屏）

#### 5.2.1 输入映射

| 输入 | 行为 | 优先级 |
|---|---|---|
| 鼠标移动（在画布上） | 相机轻微摆动（az/el 偏移） | 写生默认 |
| 鼠标滚轮 | 缩放距离（0.4 ~ 60 单位） | — |
| 单指拖动 | 旋转视角 | 触屏默认 |
| 双指捏合 | 缩放 | — |
| 双指旋转 | 旋转 | — |
| Apple Pencil 笔尖拖动 | 同单指，但**不画线**（避免误触发） | — |

> **关键决策**：触屏和笔在画布上拖动时，**默认不画线**，而是旋转视角。画线需要点工具栏的"画笔"按钮进入绘画模式。
>
> **理由**：艺考生写生时大量时间是"观察"，不需要一直画；如果默认画线，手掌误触会留下大量脏笔触。

#### 5.2.2 滑块参数

| 参数 | 范围 | 默认 | 影响 |
|---|---|---|---|
| 灵敏度 | 0-100% | 50% | 鼠标移动 → 相机偏移的映射系数 |
| 摆动范围 | 0-100% | 30% | 最大偏移角度（限制在 ±15°） |
| 阻尼 | 0-1 | 0.15 | 视角平滑程度（越大越迟钝） |

#### 5.2.3 边界

- 鼠标移出画布 → 1 秒内回正（缓动）
- 触屏双指离开后 → 维持当前视角

### 5.3 F-003 · 预设视角

#### 5.3.1 6 个预设的球坐标参数

| 预设 | az (°) | el (°) | dist |
|---|---|---|---|
| 正面 | 0 | 0 | 1.5 |
| 3-4 侧（左） | -45 | 5 | 1.6 |
| 全侧（左） | -90 | 0 | 1.5 |
| 3-4 后 | -135 | 5 | 1.6 |
| 背面 | 180 | 0 | 1.5 |
| 顶视 | 0 | 75 | 1.8 |

> dist 是相对于 fit-to-view 距离的倍数。

#### 5.3.2 切换动画

- 缓动函数：`ease-out cubic`，时长 400ms；
- 切换过程中禁用其他视角输入（避免混乱）。

#### 5.3.3 快捷键

| 键 | 行为 |
|---|---|
| F | 正面 |
| S | 3-4 侧 |
| T | 顶视 |
| R | 全侧（右） |
| 1-6 | 对应上面 6 个预设 |
| W | 切换线框模式 |
| G | 切换网格底盘 |
| Z / Y | 撤销 / 重做（仅绘画模式） |
| B | 切换画笔 / 视角模式 |

#### 5.4.1 4 套经典布光预设参数

| 预设 | 主光 az (°) | 主光 el (°) | 强度 | 适用 |
|---|---|---|---|---|
| 平光 | 0 | 30 | 0.6 | 基础练习 |

| 参数 | 范围 | 默认 | 影响 |
|---|---|---|---|
| 水平角 | 0-360° | 0 | 主光方位 |
| 仰角 | -90° ~ +90° | 30 | 主光俯仰 |
| 强度 | 0-200% | 100% | 主光亮度 |
| 环境光 | 0-100% | 30% | 整体环境亮度 |

### 5.5 F-005 · 网格底盘

#### 5.5.1 元素

- **基座**：暗灰色（#2a2a2a）圆盘，直径 = 模型包围盒 × 2.0
- **高光圈**：香槟金（#c89d5e）细圈，宽度 2px
- **主网格**：4×4 米，黄褐色（#8a7048），不透明度 60%
- **远景网格**：20×20 米，灰色（#5a5a5a），不透明度 30%

#### 5.5.2 控制

- 显示/隐藏
- 半径（基座大小）
- 不透明度

---

### 5.6 F-006 · 画板（核心）

#### 5.6.1 进入绘画模式

- 默认：视角模式（触屏拖动 = 旋转）
- 点击工具栏"画笔"按钮 → 进入绘画模式
- 绘画模式下：
  - 触屏/笔拖动 = 画线
  - 单指离开 = 当前笔触结束
- 再次点击工具栏"视角"按钮 → 退出绘画模式

> **注意**：绘画模式和视角模式的切换是显式的，**没有自动切换**。避免误操作。

#### 5.6.2 画板参数

| 参数 | 范围 | 默认 |
|---|---|---|
| 颜色 | 黑/白/灰/红/蓝 | 黑色 |
| 线宽 | 1-50 px | 4 px |
| 画板不透明度 | 0-100% | 80% |
| 压感 | 开/关 | 开 |

#### 5.6.3 撤销/重做

- 命令模式：每次笔触结束 = 1 个命令
- 栈深度：200 步
- 性能：每 10 步做一次离屏快照
- 快捷键：Z / Y

#### 5.6.4 导出

- 点击"截图" → 合成 3D 视图 + 画板层 → 下载 PNG
- 文件名：`sketch-{modelId}-{YYYYMMDD-HHMMSS}.png`

#### 5.6.5 边界

| 情况 | 处理 |
|---|---|
| 笔触超过 200 步 | 最早步骤被丢弃 |
| 浏览器不支持 pressure | 退化为恒定线宽，UI 提示 |
| 双指捏合时 | 不画线，仅缩放 |
| 画板在折叠侧栏时 | 正常工作（避免 resize 引起的坐标问题） |

---

### 5.7 F-007 · 同框对比

#### 5.7.1 面板位置

- 右侧 50% 宽，覆盖在画布之上（不挤占 3D 视图）
- 顶部 50% = 用户画的（合成图）
- 底部 50% = 参考原图（如 natural.png）

#### 5.7.2 控制

- 透明度滑块（参考图）：0-100%
- 关闭按钮

---

### 5.8 F-008 · 截图保存

- 合成：3D 视图 canvas + 画板 canvas → 一个 PNG
- 通过 `canvas.toDataURL('image/png')` + `<a download>` 触发下载
- 文件名格式：`sketch-{modelId}-{ISO 时间戳}.png`

### 5.9 F-010 · 离线（PWA）

- manifest.webmanifest：name / icons / display=standalone / theme-color
- Service Worker 预缓存：index.html + CSS + Three.js bundle
- IndexedDB：缓存已下载的模型 GLB

## 6. 状态机

### 6.1 全局状态

```
IDLE  ──选模型──> LOADING  ──完成──> READY
                                          │
                          ┌─────绘画模式───┤
                          ▼               │
                       PAINTING  <───"画笔"按钮──┐
                          │                    │
                          └───────"视角"按钮──> READY
```

### 6.2 加载状态

```
IDLE → FETCHING → PARSING → READY
            │         │
            └──失败─→ ERROR (toast + 重试按钮)
```

## 7. 错误处理矩阵

| 错误 | 提示 | 恢复策略 |
|---|---|---|
| 模型 GLB 加载失败 | toast"加载失败" | 自动重试 1 次，失败则回退到上一模型 |
| IndexedDB 写入失败 | toast"存储失败" | 提示用户清理空间 |
| Service Worker 注册失败 | 不提示（PWA 不影响功能） | — |
| 触屏不支持 Pointer Events | 弹窗"您的浏览器版本过低" | 提供 Chrome/Safari 下载链接 |
| Apple Pencil 压感失效 | 控制台警告 | 退化为恒定线宽 |

## 8. 数据存储与多用户

> 详见 **[09-data-strategy.md](./09-data-strategy.md)** —— 本节只是概要。

### 8.1 核心策略

- **v1.0**：设备本地、**匿名多用户**、可导出、可删除
- **v1.1**：加手机号/微信登录、云同步
- 数据按用户完全隔离；删除用户连带删除其全部数据

### 8.2 三层存储

| 数据 | 存储 | 隔离粒度 | 生命周期 |
|---|---|---|---|
| 用户列表 / 当前用户 ID | localStorage | 全设备共享 | 永久 |
| 用户偏好（光源/视角/画板） | localStorage.userPrefs.{userId} | 每用户 | 永久直到删除用户 |
| 模型 GLB 缓存 | IndexedDB.sketch-ref-v1--{userId}.models | 每用户独立库 | 永久直到清理 |
| 截图作品 | IndexedDB.sketch-ref-v1--{userId}.artworks | 每用户独立库 | 永久直到删除 |
| 撤销栈（200 步） | 内存 | 当前用户会话 | 单次会话 |

### 8.3 关键约束

- **每个用户一个独立 IndexedDB 数据库**（不是一个大库多 store）→ 删用户 = 删一个数据库
- **每个持久化对象带 schemaVersion** → 数据结构演进自动迁移
- **用户可导出 zip**（含 prefs + 模型 + 作品）
- **用户可彻底删除**（含全部数据）
- **iOS Safari 7 天不用可能清掉 IDB** → UI 提示定期导出
