## 2. 用户故事 + 验收标准

### F-001：模型库浏览

**故事**：作为集训生，我想看到分类清晰的头部模型列表，能点击切换。

**验收标准**：
- GIVEN 用户进入 App
  WHEN 默认加载
  THEN 顶部出现"模型库"标签页 + 当前模型名称
- GIVEN 模型列表
  WHEN 点击某个模型
  THEN 3D 视图在 3 秒内切换到该模型，相机自动 fit-to-view
- 模型分类维度：**性别**（男/女）× **年龄**（青年/中年/老年）× **角度**（正面/3-4 侧/全侧）

**未实现**：当前只有 `model.glb` 1 个模型，**需要用 `scripts/meshify.py` 生成至少 30 个**。

---

### F-002：鼠标/触控笔驱动视角微动 ✅（已实现）

**故事**：作为用户，我想让相机像写生时头部那样轻微摆动，而不是固定死板。

**验收标准**：
- 鼠标在画布上移动 → 相机绕模型做 az/el 偏移；
- 鼠标移出画布 → 1 秒内自动回正；
- 灵敏度/摆动范围/阻尼 三个滑块可调；
- 触屏：单指拖动旋转，**双指捏合缩放**（v1.0 增量）。

**状态**：✅ 鼠标部分已在 `index.html` 实现，**触屏 / Apple Pencil 部分待做**。

---

### F-003：6 个预设视角 ✅（已实现）

**故事**：作为用户，我想一键切到"3-4 侧光"这种经典练习角度。

**验收标准**：
- 6 个按钮：正面 / 3-4 侧 / 全侧 / 3-4 后 / 背面 / 顶视；
- 快捷键 F/S/T/R；
- 切换有 0.4s 平滑过渡动画（避免突兀）。

**状态**：✅ 已实现，见 commit `d3b9882`。

---

### F-004：主光源控制 ✅（已实现）

**故事**：作为用户，我想调节光源方向来控制明暗交界线。

**验收标准**：
- 水平角滑块（0-360°）；
- 仰角滑块（-90° ~ +90°）；
- 强度滑块（0-200%）；
- 环境光强度滑块（0-100%）；
- **新增**：4 套经典布光预设（平光 / 侧光 / 顶光 / 伦勃朗光）按钮。

**状态**：✅ 滑块已实现；❌ 4 套预设未加。

---

### F-005：网格底盘 ✅（已实现）

**故事**：作为用户，我想看到地面网格来感知模型的空间位置。

**验收标准**：
- 圆形暗灰基座（直径 = 模型包围盒 × 2.0）；
- 香槟金高光圈；
- 4×4 主网格 + 20×20 远景网格（颜色衰减）；
- 显示/隐藏开关、半径滑块、不透明度滑块。

**状态**：✅ 已实现，见 commit `d3b9882`。

---

### F-006：画板叠加 ❌（核心待实现）

**故事**：作为用户，我想在 3D 视图上直接用触控笔画画。

**验收标准**：
- 画板 Canvas 叠在 3D Canvas 之上，半透明（不透明度可调 0-100%）；
- 触屏/笔/鼠标都能画；
- **压感**：Apple Pencil 1/2 压感有效（线条粗细随压力变化）；
- 颜色可选：黑 / 白 / 灰 / 橡皮；
- 线宽滑块（1-50 px）；
- **撤销/重做**（至少 50 步）；
- 隐藏/显示画板开关（用于"先观察再画"）；
- 工具栏折叠时画板正常。

**状态**：❌ **完全未做，最高优先级**。

**技术风险**：
- Pointer Events pressure 在不同浏览器差异大；
- 高 DPI 画板锯齿；
- 双指缩放和单指绘画冲突。

**缓解**：见 [02-feasibility-analysis.md §2.2](./02-feasibility-analysis.md) + [06-verification-plan.md](./06-verification-plan.md) §2。

---

### F-007：同框对比（用户画 vs 参考）❌

**故事**：作为用户，我想把自己的画和参考原图放在一起对比。

**验收标准**：
- 右侧弹出面板：
  - 上半：自己画的（PNG 缩略图）
  - 下半：参考原图（natural.png 风格）
- 透明度滑块可调"参考图"的不透明度（用于叠在画面上看差距）；
- 关闭按钮。

**状态**：⚠️ 当前有"原图对比"（右上角贴一张参考图），但**没有"用户作品 vs 参考"的并排**。

---

### F-008：截图保存 ✅（已实现）

**故事**：作为用户，我想保存当前视角。

**验收标准**：
- 点击"截图"按钮 → 当前 3D 视图导出 PNG（不含 UI）；
- 文件名 `sketch-ref-YYYYMMDD-HHMMSS.png`。

**状态**：✅ 已实现。

---

### F-009：原图对比 ✅（已实现）

**故事**：作为用户，我想把参考原图贴在画面角落对照。

**验收标准**：
- 开关按钮；
- 出现位置：右上角；
- 可关闭；
- 可拖动位置（v1.1）。

**状态**：✅ 已实现。

---

### F-010：离线启动 ❌

**故事**：作为用户，我想在没有网络的教室/地铁里也能用 App。

**验收标准**：
- 首次访问后，离线启动 App；
- 已下载的模型离线可用；
- 离线状态下，画板 + 截图本地保存。

**状态**：❌ 完全未做。

---

### F-011：背景色与显示选项 ✅（部分实现）

**验收标准**：
- 背景色预设：米白（默认）/ 纯黑 / 灰色 / 透明；
- 线框模式开关（W 快捷键）；
- 水平镜像开关。

**状态**：✅ 部分实现。

## 3. 非功能验收

| 项 | 目标 |
|---|---|
| iPad Air 加载 30 个模型（首次全部下载完） | ≤ 2 分钟 |
| 单模型切换 | ≤ 3 秒 |
| 画板 100 笔画渲染 | ≥ 30 FPS |
| 撤销 50 步 | ≤ 100ms |
| 包体 | ≤ 5 MB（不含模型） |
| Lighthouse PWA 评分 | ≥ 90 |
