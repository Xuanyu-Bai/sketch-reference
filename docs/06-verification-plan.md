## 1. 验证策略总览

```
┌──────────────────────────────────────────────────────────┐
│  L1 · 单元验证（开发者本地）                              │
│      ↓ 通过                                                │
│  L2 · 关键路径手测（开发者 + 设计自测）                    │
│      ↓ 通过                                                │
│  L3 · 跨设备手测（iPad / Android / Desktop）              │
│      ↓ 通过                                                │
│  L4 · 性能基准（FPS / 加载时间 / 包体）                    │
│      ↓ 通过                                                │
│  L5 · 用户验收（5-10 名艺考生内测）                        │
└──────────────────────────────────────────────────────────┘
```

**原则**：v1.0 不上自动化测试框架（手测成本低于维护成本）；v1.1+ 再考虑 Playwright。

## 2. L1 · 关键路径手测清单

> 每完成 Phase A/B 一个任务，就跑对应清单。

### 2.1 3D 渲染

| 用例 | 步骤 | 预期 |
|---|---|---|
| 模型加载 | 选模型 → 等待 | 3 秒内显示，相机自动 fit |
| 视觉中心 | 加载半身像 → 检查画面 | 脸在画面正中 |
| 视角微动 | 鼠标在画布上滑动 | 相机轻微摆动，移出回正 |
| 预设视角 | 点"3-4 侧"按钮 | 0.4s 平滑切到目标角度 |
| 截图 | 点截图按钮 | 下载 PNG，文件不含 UI |
| 线框模式 | 按 W | 切换正常 |
| 水平镜像 | 点镜像 | 模型左右翻转 |
| NDC 偏移 | 折叠侧栏 | 模型位置不变 |
| 工具栏折叠 | 点 ⇥ 按钮 | 画布占满，渲染尺寸更新 |

### 2.2 画板（核心新增）

| 用例 | 步骤 | 预期 |
|---|---|---|
| 单指画 | 单指拖动 | 出线条 |
| Apple Pencil 画 | 笔尖压 + 拖 | 线条粗细随压力变化 |
| S Pen 画 | 笔尖压 + 拖 | 同上 |
| 双指缩放 | 双指捏合 | 3D 视图缩放，**不画线** |
| 双指旋转 | 双指旋转 | 3D 视图旋转 |
| 撤销 | 双击 / 按钮 | 撤销最近一笔 |
| 重做 | 按钮 | 恢复最近撤销 |
| 50 步撤销 | 连点 50 次 | 无卡顿 |
| 颜色切换 | 点黑/白/灰 | 下一笔用新颜色 |
| 线宽切换 | 拖滑块 | 下一笔新粗细 |
| 橡皮 | 切橡皮 | 擦除笔触 |
| 透明度 | 拖滑块 | 画板可见度变化 |
| 隐藏画板 | 开关 | 露出 3D 视图 |
| 截图含画板 | 截图按钮 | PNG 包含画板层 |

### 2.3 模型库

| 用例 | 步骤 | 预期 |
|---|---|---|
| 列表渲染 | 进入模型库 | 30 个模型卡片 |
| 按性别筛选 | 点"男" | 只显示男模型 |
| 按年龄筛选 | 点"中年" | 只显示中年 |

| 网络断开 | 断网访问已下载模型 | 仍可用 |

### 2.4 PWA 离线

| 用例 | 步骤 | 预期 |

| 安装 | Safari → 添加到主屏幕 | 图标出现 |

### 2.5 同框对比

| 用例 | 步骤 | 预期 |
|---|---|---|
| 打开对比 | 开关 | 右侧弹出面板 |

## 3. L3 · 跨设备测试矩阵

### 3.1 设备清单

| 设备 | OS | 浏览器 | 触控笔 |
|---|---|---|---|
| iPad Air 4 | iPadOS 17 | Safari | Apple Pencil 2 |
| iPad mini 6 | iPadOS 17 | Safari | Apple Pencil 2 |
| 小米平板 5 | Android 13 | Chrome | 第三方电容笔 |
| 三星 Tab S8 | Android 13 | Chrome | S Pen |
| MacBook Pro 14 | macOS 14 | Chrome / Safari | — |
| Surface Pro 7 | Windows 11 | Edge / Chrome | Surface Pen |
| iPhone 14 | iOS 17 | Safari | — |

### 3.2 每个设备必跑

1. 加载默认模型，截图对比
2. 切 3 个预设视角
3. 画 10 笔画 + 撤销 5 步
4. 截图保存 PNG，检查大小
5. 离线启动

### 3.3 已知差异点（需重点观察）

| 差异 | 观察项 |
|---|---|
| iOS Safari WebGL 性能 | FPS |
| iOS Safari IndexedDB 限额 | 30 个模型总大小是否触发 |
| Android Chrome pressure 支持 | S Pen vs 电容笔 |
| 双指手势冲突 | 缩放 vs 绘画 |
| 高 DPI 锯齿 | iPad Retina 上画板 |

## 4. L4 · 性能基准

### 4.1 基准测试方法

用浏览器 Performance API：
```js
performance.mark('model-load-start');
await loadModel(id);
performance.mark('model-load-end');
performance.measure('model-load', 'model-load-start', 'model-load-end');
```

### 4.2 指标 & 目标

| 指标 | 目标 | 不通过阈值 |
|---|---|---|
| 首屏加载（FCP） | ≤ 1.5 s | > 3 s |
| 模型切换 | ≤ 3 s（首次） / ≤ 0.5 s（缓存命中） | > 5 s |
| 画板帧率（iPad Air 4） | ≥ 30 FPS | < 24 FPS |
| 撤销 50 步耗时 | ≤ 1 s（总） | > 3 s |
| 包体（不含模型） | ≤ 5 MB | > 8 MB |
| Lighthouse PWA | ≥ 90 | < 80 |
| Lighthouse Performance | ≥ 80 | < 70 |
| Lighthouse Accessibility | ≥ 90 | < 80 |

### 4.3 测试产物

- `lighthouse-report.html`（每次 release 跑）
- `perf-trace.json`（Chrome DevTools Performance trace）

## 5. L5 · 用户验收测试（UAT）

### 5.1 招募

- 5-10 名艺考生（高一~高三）；
- 招募渠道：本地画室、艺考社群；
- 每人发一台 iPad Air 装 TestFlight / 网页；
- 周期：1 周。

### 5.2 测试任务

每位用户完成 5 个任务：

1. **基础临摹**（20 分钟）
   - 选一个头部模型
   - 调光源到喜欢的角度
   - 用 Apple Pencil 画 10 笔
   - 截图保存

2. **预设切换**（5 分钟）
   - 试 6 个预设视角
   - 找到最喜欢的 1 个

3. **同框对比**（10 分钟）
   - 画 5 笔
   - 打开对比面板看自己画的和参考图

4. **离线**（5 分钟）
   - 飞行模式
   - 启动 App
   - 加载已下载的模型

5. **反馈问卷**（10 分钟）
   - 整体满意度（1-10）
   - 最喜欢的功能
   - 最不喜欢的功能
   - 缺失的功能
   - 是否愿意付费（¥30/月 / ¥200/年）

### 5.3 通过标准

| 指标 | 目标 |
|---|---|
| 5 个任务全部完成率 | ≥ 80% |
| 整体满意度 | ≥ 7/10 |
| 付费意愿 | ≥ 30% |
| P0/P1 反馈 | ≤ 5 条 |

## 6. 回归测试清单（每次发版）

```
□ 加载 30 个模型
□ 切 6 个预设视角
□ 鼠标/笔/触屏 各画 10 笔
□ 撤销/重做 50 步
□ 截图保存
□ 折叠/展开侧栏
□ 离线启动
□ 切换模型库分类筛选
□ 关闭再开 App（IndexedDB 持久化）
□ Lighthouse 跑分
```

预计耗时：1 人 × 1 天。

## 7. Bug 分级标准

| 级别 | 定义 | SLA |
|---|---|---|
| P0 | App 崩溃 / 核心功能不可用 | 24h 修 |
| P1 | 主要功能异常但有 workaround | 1 周 |
| P2 | 次要功能 / UI 问题 | 下个 sprint |
