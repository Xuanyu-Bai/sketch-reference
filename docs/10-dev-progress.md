## 用户流程验证

### ✅ 启动流程
1. 访问 http://127.0.0.1:8767/index.html
2. SW 自动注册（`[SW] registered`）
3. 自动创建默认用户"用户1"（localStorage）
4. 自动加载 model.glb（首次走网络 → 写入 IDB；二次直接命中）
5. 渲染 3D 头部模型
6. 显示欢迎 toast

### ✅ 视角控制
- 鼠标在画布上滑动 → 相机轻微摆动
- 移出画布 → 视角回正
- 滚轮 → 缩放
- 6 个预设视角按钮（正面/3-4 侧/全侧/3-4 后/背面/顶视）
- 快捷键 F/S/T/R

### ✅ 光源控制
- 水平角 / 仰角 / 强度 / 环境光 滑块
- 4 套经典布光预设（平/侧/顶/伦）
- 实时更新 3D 场景 + 持久化偏好

### ✅ 画板
- 点击"画笔"按钮进入绘画模式
- 触屏/笔/鼠标 都能画
- 压感支持（线条粗细随压力变化）
- 5 色选择器
- 线宽 / 不透明度滑块
- 撤销 / 重做 / 清空
- 快捷键 B / Z / Y

### ✅ 多用户
- 顶栏头像"用"（设备主人）
- 点击展开菜单：当前用户 / 切换 / 新建 / 导出 / 导入 / 删除
- 每个用户独立偏好 + 独立 IDB 数据库
- 切换用户自动重新加载 UI

### ✅ PWA
- manifest.webmanifest 配置完整
- sw.js 注册成功
- Service Worker 缓存策略：cache-first for shell + network-first for GLB

### ✅ 同框对比
- 点击"原图对比"打开右栏面板
- 上半：当前画板快照
- 下半：natural.png（参考图）
- 参考图透明度滑块
- 刷新按钮重新捕捉画板

## 已知限制

| 限制 | 影响 | 解决 |
|---|---|---|
| Python `http.server` MIME 全错 | SW 无法注册 | 已写 `serve.js`，start.bat 优先用它 |
| iOS Safari IndexedDB 限额 ~500 MB | 模型缓存可能被清 | UI 文案 + 导出功能 |
| 中文 UI 国际化 | 仅中文 | v2.0 加 i18n |
| 测试无自动化 | 全手测 | v1.1 加 Playwright |
